# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Repository structure and documentation
- CI/CD workflow with GitHub Actions
- Development tooling configuration (ESLint, Prettier, TypeScript)

## [0.1.0] - 2024-12-20

### Added
- Real-time metrics monitoring system
- WebSocket-based metric streaming
- PostgreSQL database with Drizzle ORM
- User authentication with Replit Auth
- Alert configuration and threshold monitoring
- React frontend with shadcn/ui components
- Express backend with TypeScript
- Shared type definitions between client and server
- Responsive metric visualization with Recharts

### Infrastructure
- Vite build system for client
- ESBuild bundler for server
- Development hot-reload
- Database migrations with Drizzle Kit
